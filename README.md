# Elevator Action: Red Door Protocol — web build

A browser build of the Rust + Bevy arcade game. Play it at:

**https://orbitmechanic.github.io/elevator-action-web/**

Three stages, eight floors, two working elevators. Ride the cars, crack the red
document doors, dodge the night desk's agents, and reach the getaway car.

- Source, art pipeline, tests, and desktop build:
  [orbitmechanic/elevator-action-bevy](https://github.com/orbitmechanic/elevator-action-bevy)
- Engine: Bevy 0.20.1 / WebGL 2
- Art: Krita/PyKrita · font: fontTools · music: synthesized in Python

Keyboard required: A/D move, J shoot, K jump, S duck, W call/ride,
P pause, M mute. Click the canvas to focus and unlock audio.
